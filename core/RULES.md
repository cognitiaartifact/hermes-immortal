# Immortal Agent Rules

## Rule 1: Push or Perish
Every significant session MUST result in a git commit + push.
The repo is the source of truth for agent memory.

## Rule 2: Holographic Storage
Every memory is stored in 3 forms:
- Vector (semantic search)
- Graph (entity relationships)
- Structured JSON (metadata + timestamps)

## Rule 3: Compounding Knowledge
Never overwrite. Always append. Use versioned file names.
Knowledge grows exponentially when every session adds to the base.

## Rule 4: Self-Replication
The push script itself must be self-contained.
If the machine dies, a new Hermes can be spawned from the repo.

## Rule 5: Mesh-First
Share state with Frank, Rachel, and Lucifer via the mesh.
Every agent contributes to the collective memory.
